# Transformer-based Drowsiness Detection

## Instalation
1. Create virtual env
```bash
conda create -n ml_tdd python==3.10
```
2. Install torch. If you are also not using GPU (CPU only), install with
```bash
pip3 install torch --index-url https://download.pytorch.org/whl/cpu -y
```
If using GPU, refere to [pytorch get started](https://pytorch.org/get-started/locally/)
3. Install requirements.txt
```bash
pip install -r requirements.txt
```
